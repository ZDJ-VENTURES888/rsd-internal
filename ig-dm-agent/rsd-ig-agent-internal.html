  • Supabase schema applied (docs/schema.sql)
  • All .env vars set — Anthropic, Supabase, GHL, notifications
  • ManyChat Pro active ($15/mo)
  • Instagram Business account connected to ManyChat
  • External Request block configured with webhook URL + secret
  • Opener flow tested — is_opener=true returns correct DM
  • Trigger keyword set to specific post (never Any Post)
  • 3–4 public reply variations added to ManyChat
  • ManyChat notification configured for Zack/Joel on handoff

Post-Launch Verification (First 10 Minutes)

  • Comment trigger keyword from personal account — DM arrives in <5 seconds
  • Public reply visible on the comment
  • Claude opening message: no exclamation points, no filler, RSD voice confirmed
  • Phase 1/2/3 language used — no reef-themed names
  • API call registering at console.anthropic.com under correct key
  • Conversation record created in Supabase conversations table
  • Human handoff notification fires on booking intent — email/SMS received
  • GHL contact created on qualified or handoff status
